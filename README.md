
# KioskTSD

Киоск-браузер в моем случае для веб-клиента 1С на Android-терминалах сбора данных (проверялось на Mindeo, Android с GMS). Состоит из двух приложений:

| Приложение | Пакет | Назначение |
|---|---|---|
| **1C Viewer** | `com.onec.viewer` | Полноэкранный просмотрщик веб-клиента 1С без адресной строки, меню и системных панелей |
| **1C Config** | `com.onec.config` | Настройки: ссылка на базу 1С и параметры просмотрщика |

## Возможности

- Полноэкранный режим (immersive): скрыты статус-бар и кнопки навигации.
- Экранная клавиатура не появляется при фокусе на поле ввода. Печатать можно с физической клавиатуры ТСД, также работает ввод со сканера штрихкодов в режиме эмуляции клавиатуры. Режим отключается галочкой в Config.
- Сессия не теряется: куки без срока жизни сохраняются и восстанавливаются при запуске со сроком в один год, как это делает Chrome. Состояние страницы переживает пересоздание активности.
- Кнопка «Назад» ходит по истории браузера и не закрывает приложение.
- При обрыве связи показывается страница с кнопкой «Повторить».
- Опция «Не гасить экран».
- Поддерживается `http://` (cleartext traffic включён), так как 1С часто работает во внутренней сети без HTTPS.
- Нет внешних зависимостей (только Android SDK, без AndroidX).

## Как это работает

Config хранит настройки в `SharedPreferences` и отдаёт их через `ContentProvider` (`content://com.onec.config.provider/cfg`). Viewer читает их при каждом возвращении на экран, поэтому смена ссылки подхватывается без переустановки. Последние полученные значения Viewer кэширует у себя, так что он работает и без Config.

Блокировка клавиатуры построена на флаге окна `FLAG_ALT_FOCUSABLE_IM`, который отвязывает окно от метода ввода. Дополнительно полям на странице выставляется `inputmode="none"`.

## Готовые сборки

В релизах репозитория лежат два готовых APK, собранных и подписанных автором:

- `viewer.apk` — 1C Viewer
- `config.apk` — 1C Config

Их можно сразу установить на терминал, не собирая проект самостоятельно. Оба файла подписаны одним ключом автора. Если вы соберёте проект сами и подпишете другим ключом, установить его поверх готовых сборок не получится: сначала удалите старую версию.

## Сборка

Требования: Android Studio (или Gradle 8.7+), JDK 17, Android SDK 34.

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. Соберите оба модуля:
   - из терминала: `./gradlew assembleDebug` (или `gradle assembleDebug`, если wrapper не сгенерирован);
   - либо через Build → Build APK(s).
3. Готовые файлы:
   - `viewer/build/outputs/apk/debug/viewer-debug.apk`
   - `config/build/outputs/apk/debug/config-debug.apk`

Для запуска из Android Studio выберите нужный модуль (`viewer` или `config`) в выпадающем списке рядом с кнопкой Run.

## Установка и настройка

1. Установите оба APK (готовые из релизов или собранные самостоятельно) на терминал (`adb install -r <файл>.apk`).
2. Откройте **1C Config**, введите ссылку на веб-клиент, например `https://server/base/ru_RU/`. Если схема не указана, подставляется `https://`.
3. Нажмите «Сохранить и открыть». Запустится Viewer с указанной ссылкой.
4. Чтобы сменить ссылку или параметры, снова откройте Config.

## Ограничения

- Если сессию завершает сервер 1С по тайм-ауту, приложение это не обходит. Настраивайте время жизни сеанса на стороне сервера.
- Экранной клавиатурой в режиме «без клавиатуры» пользоваться нельзя (это его назначение), набирать текст нужно физической клавиатурой ТСД. Если нужна экранная клавиатура, снимите галочку в Config.
- Сканеры, передающие данные через broadcast Intent, а не клавишами, требуют отдельного приёмника.
- Куки восстанавливаются с `Path=/`, а флаг `HttpOnly` при восстановлении теряется.
- Ошибки SSL не игнорируются: для самоподписанных сертификатов добавьте сертификат в доверенные на устройстве.
